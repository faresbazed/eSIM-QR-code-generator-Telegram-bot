بوت تليجرام لتحويل شرائح eSIM (QR Code ⇄ LPA) | Arabic eSIM Telegram Bot
بوت تليجرام متكامل باللغة العربية لتحويل أكواد LPA وصور QR Code الخاصة بشرائح الـ eSIM إلى رسالة كاملة تحتوي على:
￼ صورة QR Code عالية الدقة جاهزة للمسح.
￼ استخراج تلقائي لـ عنوان السيرفر (⁠SM-DP+⁠) وكود التفعيل والكود اليدوي الكامل (⁠LPA:1$...⁠) قابل للنسخ بضغطة واحدة.
￼ روابط التركيب التلقائي المباشر لكل من iOS (الأيفون) وAndroid (الأندرويد).
￼ أزرار تفاعلية (⁠Inline Keyboard Buttons⁠) للتركيب المباشر (⁠📲 تركيب على الأيفون⁠ و⁠🤖 تركيب على الأندرويد⁠) مطابقة للصورة المرفقة.
￼ نظام إشعارات وتحويل كامل للأدمن: تصل للأدمن كل الرسائل المرسلة للبوت مع بيانات المرسل (⁠الاسم⁠، ⁠@اليوزر⁠، ⁠ID⁠، وحالة التحويل) وصورة الـ QR أو الرسالة أسفلها، مع إمكانية الرد المباشر (Reply) من الأدمن ليصل الرد للمستخدم عبر البوت، بالإضافة لأوامر الحظر (⁠/ban⁠ و⁠/unban⁠).
